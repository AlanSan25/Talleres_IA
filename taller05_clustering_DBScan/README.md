# Taller05-IA — Clustering DBSCAN

Solución reproducible del taller en [`taller_05_DBSCAN.ipynb`](taller_05_DBSCAN.ipynb).

El cuaderno genera una figura sintética propia con 20 grupos amorfos y outliers uniformes, implementa DBSCAN desde cero, estudia curvas de k-distancia y evalúa el resultado mediante ARI y silueta.

## Ejecución

```bash
python -m pip install -r requirements.txt
jupyter notebook taller_05_DBSCAN.ipynb
```

Antes de entregar, complete los nombres de los integrantes en la primera celda y publique el contenido en el repositorio de GitHub que compartirán con el profesor.
